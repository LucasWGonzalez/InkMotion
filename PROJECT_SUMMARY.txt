1. Instalar y ejecutar:

2. Abrir en navegador:
   http://localhost:8080

3. Probar en dispositivo móvil (misma red):

4. Flujo de uso:

   - Mueve el dispositivo para ver parallax 3D
   - En dispositivo real: busca la imagen para detectarla

================================================================================
  🐛 TROUBLESHOOTING
================================================================================

"MindAR SDK no disponible"
  → Normal, funciona en modo demo
  → En producción la CDN se cargará correctamente

"Cámara no disponible"
  → En el navegador de prueba no hay cámara física
  → Prueba en un dispositivo móvil real

"Parallax no funciona"
  → Verifica DeviceOrientation en F12 console
  → En desktop, mueve el ratón o toca la pantalla

"Puerto 8080 ocupado"
  → npm start --port 8081 (cambiar puerto)
